# 天使王國島・靈魂覺醒

天使王國島的「靈魂覺醒」互動頁面：揭開六道幻象，長按開啟天使之門。

## 互動內容

- **六道幻象時間軸**：點擊 01–06 節點閱讀說明，看完前五道後「靈魂覺醒」節點會發光。
- **旅程階段**：「揭開幻象 × 記起自己 × 穿越光之門」隨進度亮起。
- **長按開啟天使之門**：光圈會跟著影片中拱門的位置移動；按住約 2 秒進度環填滿即開門，中途放開會回退。鍵盤可按住空白鍵或 Enter。
- **開門轉場**：畫面衝進門內、白光爆亮，進入「歡迎回到天使王國島」，可按「再走一次」重來。
- **前景特效**：Canvas 即時繪製的羽毛與光點。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面（HTML、CSS、JavaScript 都在同一個檔案） |
| `assets/gate.mp4` | Midjourney 生成的 5 秒循環背景影片（768×512） |
| `assets/gate.jpg` | 影片載入前的預覽圖，也是減少動態設定下的靜態背景 |
| `assets/gate-m.mp4` | 手機直式專用影片：裁出手機畫面看得到的中段（原影片 x 170–570），放大到 1080 寬並降噪、銳化 |
| `assets/gate-m.jpg` | 手機直式專用預覽圖 |

## 在本機預覽

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。

## 更換背景影片

替換 `assets/gate.mp4` 與 `assets/gate.jpg` 即可。若新影片的鏡頭有移動，需要更新 `index.html` 裡的 `TRACK` 陣列（拱門頂端每 1/8 秒的位置，以畫面寬高的比例表示），光圈才會繼續對準門口。

## 素材來源

背景畫面與影片由 Midjourney 生成。字型使用 Google Fonts 的 Noto Serif TC 與 Cormorant Garamond。
