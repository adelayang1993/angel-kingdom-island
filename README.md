# 天使王國島・靈魂旅程

從地球出發，穿越幻象與帷幕，在靈魂之鏡前喚醒內在的光，最後長按光球開啟通往天使王國島的大門。

線上版：https://adelayang1993.github.io/angel-kingdom-island/

## 六個章節

| 章節 | 互動 |
| --- | --- |
| 01 宇宙與地球 | 3D 地球（白天、夜晚城市燈光、雲層、大氣光暈）。拖曳旋轉；點擊地球，鏡頭靠近並穿越大氣層 |
| 02 降臨人間 | 從雲層降落到城市。三個主題「時間與選擇／相遇與關係／成長與覺醒」可點開 |
| 03 幻象之境 | 滑過拱門時，窗框沿形狀亮起金色光暈；點擊看見每種幻象與背後的真相。手機版改為底部五個選項，畫面會平移到選中的拱門 |
| 04 五重帷幕 | 五層 WebGL 絲綢紗幕，越深越明亮。向兩側拖曳或點擊光點逐層揭開 |
| 05 靈魂之鏡 | 光羽一開始就在湖面上輕輕起伏，腳下的光環慢慢浮現；點擊水面會起漣漪，點擊羽毛後光芒擴散、水面化為入口 |
| 06 天使之門 | 長按門中的光球開啟大門。光球會跟著影片中拱門的位置移動 |

共用功能：右側章節導覽、背景音樂與音效（瀏覽器即時合成，不需要音樂檔）、繁體中文／English 切換。網址可用 `#ch1`～`#ch6` 直接開啟某一章。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 整個頁面（HTML、CSS、JavaScript 在同一檔案），3D 使用 three.js r128（cdnjs） |
| `assets/ch1.jpg`～`ch5.jpg` | 各章背景。第 2、3 章為提供的無字原圖，其餘由視覺提案圖去除文字而來 |
| `assets/logo.webp` | 左上角天使王國島 logo |
| `assets/earth-*.jpg` | 地球貼圖（白天、夜間燈光、雲層、海面反光），取自 three.js 範例，源自 NASA Blue Marble |
| `assets/feather.webp`、`ripple.webp` | 第五章光羽與水面光環（去背後的透明圖） |
| `assets/gate*.mp4/jpg` | 第六章 Midjourney 循環影片，放大至 1536×1024 並銳化；`-m` 為手機直式高畫質版 |
| `tools/` | 去除提案圖文字所用的 Python 腳本 |

## 更換背景

各章背景直接替換 `assets/chN.jpg` 即可。若新圖構圖改變，需更新 `index.html` 中對應的座標：
- 第 1 章 `EARTH`（地球中心與半徑）
- 第 3 章 `ARCH`（五道窗框的左右邊、尖頂、弧線起點與底部，金色光暈依此描出窗框形狀）
- 第 4 章 `VCARD`（五張卡片位置）
- 第 5 章 `REST`、`TOUCH`、`HORIZON`（羽毛停留點、觸水點、水平線）

座標以原圖像素為單位。

## 在本機預覽

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。
